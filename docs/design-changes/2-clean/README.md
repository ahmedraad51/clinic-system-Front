# The clean look, before and after

**Before:** the "Midnight" design (commit 6997bc4). **After:** the "Clean" look (2026-09-30), rebuilt in DentClinic's own
code after the pet store app's admin look: white cards with 6 px corners and soft shadows on a light grey page, a white
menu that collapses to icons, a floating top bar with round icon buttons, solid violet buttons with a small lift,
outlined fields with the label above, plain tables, soft label chips, pill tabs, and people shown by their initials.
The gradients, glows, the tooth mascot, the decorative drawings and the cartoon avatars are gone. New: dark mode, a
collapsed menu, a bordered skin, a semi-dark menu and a wide page, chosen per computer in the Appearance panel.

The pictures are in English, with the dummy data on 26 September 2026. The Arabic screens are in
[docs/arabic](../../arabic/README.md). Retake the "after" pictures with `npm run screenshots:design`.
