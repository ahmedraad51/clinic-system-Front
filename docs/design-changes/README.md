# The redesign, before and after

**Before:** the plain design (commit 147e676). **After:** the "Midnight" design the clinic chose (option B), on
every screen: a dark menu with an Arabic / English switch, a colour for each part of the clinic (patients blue,
appointments magenta, treatments cyan, money green, reports orange) on each screen's header, cards, icon tiles and
charts, drawn avatars for patients and doctors, white cards with coloured edges, gradient buttons, pill tabs, and
charts on the dashboard and on Reports (revenue over time, appointments per day, treatment plans by type).

The pictures are in English, with the dummy data on 26 September 2026. The Arabic screens are in
[docs/arabic](../arabic/README.md). Retake the "after" pictures with `npm run screenshots:design`.
