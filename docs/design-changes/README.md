# Redesigns, before and after

1. [4-controls](4-controls/README.md): the app's own dropdowns, calendar, time picker, checkboxes and colour
   picker instead of the browser's, and IBM Plex Sans in both languages (2026-10-01).
2. [3-dialogs-wide](3-dialogs-wide/README.md): forms in dialogs, wide two-column record pages and the permissions
   table (2026-09-30, in the clean look).
3. [2-clean](2-clean/README.md): the clean admin look with dark mode (2026-09-30, the current design).
4. [1-midnight](1-midnight/README.md): the "Midnight" design (2026-09-30), replaced by the clean look.

The `d1-…` to `d6-…` pictures in this folder are the smaller design changes of 2026-09-28
(see [docs/reuse-from-pet-store.md](../reuse-from-pet-store.md), section 9).
